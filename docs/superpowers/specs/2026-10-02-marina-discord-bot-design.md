# 마리나 Discord 봇 — 설계

2026-10-02. 선택 기능(`~/.marina/discord.json` 있을 때만). 세션 대화 배달은 지금처럼 공식 Discord 플러그인이 하고, 봇은 **플러그인이 못 하는 것**만 맡는다.

## 왜 봇이 따로 필요한가
공식 플러그인(0.0.4)은 메시지 받기와 답장, 수정, 반응, 기록 읽기, 첨부 받기만 한다. 다음은 Discord 이벤트를 상시로 받아야 해서 플러그인 밖에 봇 연결이 하나 더 있어야 한다.
- 반응 이벤트(🛑)
- 슬래시 명령과 자동완성
- 버튼과 입력 팝업(모달)

같은 봇 토큰으로 연결을 하나 더 연다. 지금도 세션마다 하나씩 떠 있으니 자원 부담은 없다. 플러그인은 자기 `perm:` 버튼 외의 상호작용은 무시하므로 서로 겹치지 않는다(코드 확인).

## 하는 일
| # | 기능 | 동작 | Claude 토큰 |
|---|---|---|---|
| 1 | 정지 | 형 메시지의 🛑 반응(작업 시작 때 봇이 미리 달아 둠), `/stop`, 상태 메시지의 `[🛑 멈춤]` 버튼 → 그 채널 세션 tmux 에 `Esc` | 0 |
| 2 | 슬래시 명령 | 기본(`compact` `context` `model` `effort` `usage` `status` `stop`)과 모든 프로젝트의 스킬·명령을 모아 길드 명령으로 등록(최대 100, 바뀌면 다시 등록). 글자로 친 `/compact` 도 Claude 가 `slash` 도구로 넘긴다 | 0 |
| 3 | 세션 명령 실행 | `compact` `model` `effort` `/<스킬>`: 세션이 쉬는 순간(Stop 이후) tmux 입력창에 직접 친다. `/clear` 류는 막는다. 그 프로젝트에 없는 스킬이면 "없어"라고 답한다 | 명령에 따라 |
| 4 | 상태 | `/status`, `/usage`, `/context`: 봇이 파일에서 바로 답한다(형에게만 보이는 답). 컨텍스트 %, 작업 중 여부, 5h·주간 사용량, 서브에이전트(`<기록>/subagents/`), 백그라운드 작업(`tasks/*.output`), 데몬·디스크·메모리 | 0 |
| 5 | 상태 메시지 + 버튼 | 진행 스레드 상태 줄에 서브에이전트·백그라운드 표시. 작업 중일 때만 30초마다 다시 그림(쉬는 세션은 안 건드림). 버튼 `[🤖 보기]` `[⏳ 로그]` `[🛑 멈춤]` → 형에게만 보이는 창으로 내용 | 0 |
| 6 | 질문 버튼 | AskUserQuestion 을 다시 켠다. PreToolUse 훅으로 잡아(마리나 모바일 질문 카드 코드 재사용) 버튼·드롭다운으로 보낸다. `[✏️ 기타 입력…]` → 입력 팝업. 답은 tmux 키 입력으로 넣는다(모바일에서 실측) | 0 |
| 7 | 권한 승인 | 플러그인의 권한 승인 요청은 DM 으로만 간다(DM 허용 목록 비움) → 봇이 채널 버튼으로 보낸다(선택, 나중) | 0 |

## 권한·안전
- 개발 채널: 세션 `allowFrom`(형)만 버튼·명령을 쓸 수 있다. 채팅 채널: chat 역할이 있는 사람.
- 봇은 tmux 에 정해진 키(Esc, 허용 명령, 질문 답)만 보낸다. 임의 문자열은 보내지 않는다.
- 명령 원문이나 비밀값이 Discord 로 나가지 않는다(설명·파일명만).

## 구조
- `plugin/scripts/marina-discord-bot/`(bun + discord.js): 플러그인과 같은 런타임. 마리나 데몬이 discord.json 이 있을 때만 띄우고, 죽으면 다시 띄운다.
- 세션·상태 판단은 기존 `marina_session.py` 를 CLI 로 부른다(`marina session status --json` 등). 로직을 두 언어로 중복하지 않는다.
- 이벤트 위주: 세션 시작·종료·턴 종료는 기존 훅이 봇에 알린다(로컬 소켓). 시간마다 도는 감시는 "작업 중 세션의 상태 줄 30초 갱신" 하나뿐이다.

## 형 결정(2026-10-02)
- **늦게 바뀌는 표시는 쓰지 않는다.** 채널 이름 ⏳, 채널 설명 상태, 스레드 제목 ⏳/✅ 는 Discord 이름·설명 변경 제한(10분 2회) 때문에 틀린 채로 남을 수 있어 뺀다.
- 즉시 정확한 것만: 형 메시지 반응(도구별 이모지), 스레드 상태 줄(메시지 수정), `#상태` 대시보드(메시지 하나를 고쳐 씀).
- `#상태` 대시보드: 구독 5h·주간, 서버(데몬·디스크·메모리), 세션별 상태·ctx%·🤖·⏳ + 채널 링크. 턴 시작·끝, 세션 켜짐·꺼짐 때 갱신, 작업 중 세션이 있을 때만 30초마다.
- 사이드바 맨 위 **주간 사용량 숫자판**(잠긴 음성 채널 이름, 10분마다) — **형에게만 보이게**(@everyone·역할 보기 차단, 형 사용자만 허용).
- 1단계 = 🛑 정지 + `#상태` 대시보드 + 주간 숫자판.

## 순서
1. 봇 뼈대 + 정지(🛑 반응) + `#상태` 대시보드 + 주간 숫자판(형만)
2. 슬래시 명령 등록·자동완성 + tmux 로 명령 넣기(`compact` `model` `effort` `스킬`)
3. 상태 메시지 버튼(서브에이전트·백그라운드 보기)
4. 질문 버튼(+기타 입력)
5. (선택) 권한 승인 채널 버튼

각 단계는 실제 Discord 에서 확인하고 따로 커밋한다.

## 미정
- 커뮤니티 Discord 브리지 중 가져다 쓸 것이 있는지 아직 조사하지 않았다.
- 서브에이전트 도구 호출에도 PreToolUse 훅이 걸리는지 실측 필요(상태 줄 갱신이 여기에 걸려 있다).
